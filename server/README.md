# Server boundary

No server application exists in the frontend checkpoint. This directory intentionally contains no Python package, FastAPI route, configuration loader, model integration, database client, or executable file.

The next authorised phase may establish a minimal FastAPI foundation with typed contract parity, configuration validation, a health endpoint, Supabase connection planning, and an explicit mock-to-HTTP client handoff. Document ingestion, LangGraph, Gemini, retrieval, citation verification, streaming, storage, and filing remain out of that first backend phase.
